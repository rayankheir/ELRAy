# EL RAy Coffee ☕

EL RAy Coffee is a modern and responsive coffee shop website created using HTML, CSS, JavaScript, and PHP.

## Features

- Modern coffee shop design
- Responsive layout for mobile and desktop
- Smooth animations
- Best Seller section
- Coffee Menu
- Customer Reviews
- Contact form
- Email sending using PHPMailer

## Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- PHPMailer
